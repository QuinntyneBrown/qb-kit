# Code of conduct

We want qb-kit discussions and contributions to be welcoming and productive for everyone. Treat others with respect, assume good faith, and give specific, constructive feedback. Harassment, discrimination, personal attacks, threats, and sharing someone's private information without permission are unacceptable.

These expectations apply to issues, pull requests, reviews, and other project spaces. Maintainers may edit or remove comments, close discussions, or restrict participation when conduct breaks these expectations.

If you experience or observe a problem, [open an issue](https://github.com/QuinntyneBrown/qb-kit/issues/new) asking for a private contact method if the matter is sensitive. Do not post sensitive personal details publicly. Maintainers will review reports and respond as appropriate; confidentiality and response times cannot be guaranteed.
