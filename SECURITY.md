# Security policy

## Supported code

qb-kit is in early development. Security fixes are applied to the current source on the default branch. No support period for older versions has been established.

## Report a vulnerability

Please avoid opening a public issue with exploit details or sensitive information. If GitHub private vulnerability reporting is available for this repository, use [Report a vulnerability](https://github.com/QuinntyneBrown/qb-kit/security/advisories/new). Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.

If private reporting is unavailable, [open an issue](https://github.com/QuinntyneBrown/qb-kit/issues/new) requesting a private contact method without including vulnerability details. A maintainer can then arrange a private channel.

Please allow time for the report to be reviewed and coordinated before public disclosure. No response or remediation deadline is promised at this stage.
