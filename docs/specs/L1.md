# L1 - High-Level Requirements

## L1-001: Installable CLI
Developers can install `qb-kit` as a .NET tool and discover its commands through help.

## L1-002: New Angular workspace
Developers can create a runnable Angular workspace with one application under `projects/`, SCSS, routing, and strict settings.

## L1-003: Ready-to-use development tools
The new workspace provides npm commands for building, linting, formatting, and Jest unit testing, and generation verifies they work.

## L1-004: Safe and diagnosable generation
The CLI validates input and prerequisites, avoids overwriting files, and reports failed steps and cancellation clearly.
