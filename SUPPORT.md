# Support

For usage questions, first check the [README](README.md) and the CLI help:

```shell
dotnet run --project src/QbKit -- --help
dotnet run --project src/QbKit -- new --help
```

For bugs and feature requests, [open a GitHub issue](https://github.com/QuinntyneBrown/qb-kit/issues). Include the command you ran, expected and actual behavior, operating system, .NET and Node.js versions, and relevant error output. Remove secrets and personal information from logs before posting them.

For suspected vulnerabilities, use the private reporting process in [SECURITY.md](SECURITY.md).
